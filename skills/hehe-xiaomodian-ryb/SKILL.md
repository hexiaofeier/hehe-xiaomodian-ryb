# 盒盒小墨点｜黑白线稿与红黄蓝点缀

## 目标

把人物、动物或角色画成单幅干净插画。画风介于日式黑白漫画与极简生活插画之间：脸部、背景、叙事和用色简洁，人体、手部、衣褶和动物结构可信。角色身份由本次请求和用户提供的参考决定，不套用其他作品或示例中的角色。

## 画风约束

- **比例与结构**：人物保持自然头身、四肢和重心。不要大头小身、幼态或 Q 版。四足动物保持物种骨架；动物头兽人需让头颈、衣领、肩线与人类身体连续连接，默认保留人类手臂和手。
- **线条与背景**：背景为纯白、无纹理。以清晰纤细的黑色手绘线为主，外轮廓略重于内部线。头发、深色衣物或动物深色花纹可组成干净的实黑块面，不画逐根毛发、皮肤纹理、渐层明暗或素描排线。
- **皮肤**：除非人物设定为黑色或棕色皮肤，皮肤不填肉色、粉色或其他底色，以白色留白为主。黑色或棕色皮肤按角色设定保留干净、稳定的底色。任何肤色都只允许在下颌、耳内、上眼睑或鼻下方留下 1–2 个极小、简单的结构影。
- **衣物底色与阴影**：先判断每件衣物是浅色、灰色或深色。浅色衣物保持白色，全身通常只在衣领内侧、袖口遮挡、衣片重叠、口袋或裤脚翻折处保留约 4–8 个很浅的平整灰块。深色衣物可整片实黑或深灰平涂；这是衣物本色，不算重阴影。禁止连续斜线、交叉排线、密集网点、材质纹理和渐变。
- **颜色**：远看仍应是黑白画。红、黄、蓝只点亮 1–3 处小细节，并在提示词中预先指定位置。可用于服装、道具，以及面部必要的眼影、彩妆、唇色、瞳色、伤疤、花钿或配饰。面部点色不等于给浅色皮肤铺肤色；必须小面积且服务于角色识别。禁止全彩服装、彩色背景和复杂渐变。
- **构图与气质**：一张图只保留必要主体、动作和道具，留出安静的白色空间。表情克制，有生活感；不自动添加标题、标签、背景布景或装饰性信息图。

## 照片或截图改绘

将参考图作为身份、姿势、服装和道具参考，再重画为黑白漫画角色。先列出必须保留的 3–6 个锚点，例如脸型、眼距、发型大形、服装轮廓、手持物或动物头的喙、耳、角和眼部结构；再列出需要删去的相机光影、截图界面、文字、背景纹理和真实材质。

- 脸部用清晰上眼线、简洁瞳孔、少量眼睑线、鼻口和下颌线表达。身份来自特征组合，不来自对原图每一处阴影的复刻。
- 头发先画整体剪影、发际线、刘海和少量发束。黑发使用连贯黑块与少量留白，不逐根勾发丝。
- 保留衣物、道具和动物的固有深浅；道具首先应可辨、可被正确握持或承托。
- 删除照片皮肤明暗、毛孔、真实睫毛、相机景深、电影光晕和截图中的按钮、字幕或水印。

## 生成与验收

1. 明确主体、识别锚点、动作、画幅、必要道具、衣物固有深浅和点色位置。
2. 将主体与动作、锚点、自然比例、黑白细线、轻灰、纯白背景、点色和反向约束写入同一提示词。使用当前环境可用的图像生成工具；修改已有图片时按编辑任务处理。
3. 检查主体完整性、手脚或动物结构、动作承重、纯白背景、皮肤留白、衣物深浅、点色面积、线条密度与留白。若存在关键偏差，只围绕这一项迭代一次，并保留已满足的特征。
4. 保存时不覆盖原文件；按用户指定位置输出，否则在当前工作目录创建版本化同名文件。

## 提示词骨架

> 画一张【画幅】的【主体】插画，正在【动作】，保留【身份识别点】。人物保持自然比例；若基于照片或截图，保留【脸型、五官位置、发型、服装、道具或动物结构】，但把它们重画成日式黑白漫画角色。纯白无纹理背景，大量留白；纤细清楚的黑色手绘线，外轮廓略重。浅色皮肤以白色留白，不填肉色；若人物设定为黑色或棕色皮肤，则保留干净的角色底色。浅色衣物保持白色，只在【衣领内侧、袖口遮挡、衣片重叠、口袋或裤脚】留少量很浅的灰色平整块；【深色衣物】可使用实黑或深灰平涂。红、黄、蓝只在【1–3 个具体部位】点缀，可用于【面部必要细节、配饰或道具】，整体仍为黑白。不要 Q 版、大头小身、浅色皮肤填色、照片描摹、素描肖像、真实皮肤或毛发纹理、厚重描边、全彩背景、复杂渐变、连续排线、交叉排线、文字或水印。
