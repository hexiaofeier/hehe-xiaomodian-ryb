# 盒盒小墨点｜黑白线稿与灵活色彩

## 目标

把用户指定的人物、动物和动作画成干净的单幅插画。风格介于日式黑白漫画与极简生活插画之间：“简”体现在脸部表达、背景、叙事和用色，人体、手部、衣褶仍应有可信的结构。角色身份由当前请求决定，不默认套用参考图中的人物或猫。

## 画风约束

- **比例**：成人角色保持自然头身、四肢和重心；全身图通常约 6.5–8 头身，半身图不机械套用数字。儿童、青少年或特殊体型按原角色设定保留自然年龄感，不把成人意外幼态化，也不把儿童强行拉成成人比例。脸部是经过概括的漫画脸，不是照片描摹：眼、鼻、嘴、下颌各用少量有选择的线表达，五官位置清楚、神态有角色感。不要无意义的大头小身或 Q 版。四足动物保留自然骨架，不拟人化。
- **脸部肤色是硬标准**：纯白、无纹理背景。以清晰纤细的黑色手绘线为主，外轮廓略重于内部线；黑发等部位可实黑并组织成块面。除非角色设定为黑色、深棕色或其他特殊肤色，脸部不得铺肉色、粉色、米色或其他模拟肤色的底色，必须以白色留白为主；其他外露浅色皮肤原则上同样留白。可在下颌、耳内、上眼睑、鼻下等位置使用少量灰色阴影，深浅与范围按角色和画面感觉决定。黑色、深棕色或特殊肤色按角色设定保留干净、稳定的底色。不用皮肤质感、毛孔或照片式明暗来塑造脸部。
- **先判定衣物底色**：生成或改绘前，按用户要求、角色设定和参考图，判断每件衣物的固有色、灰度层级和识别作用。固有色与阴影分开处理：黑裤、深灰裤、黑鞋、深色披风等可以整片实黑或深灰平涂；彩色服装可保留固有色，也可转成灰阶。这些是衣物本色，不与阴影数量混为一谈，也不因白底黑白线稿而被强行洗白。
- **浅色衣物的阴影**：`111.png` 只是轻阴影参考，不是固定上限。根据角色、服装结构、动作和画面感觉，自主决定阴影的数量、面积和深浅；可以很少，也可以较丰富。优先让阴影交代衣领、袖口、口袋、衣片重叠、腰部和裤脚等前后关系；只要画面清楚、协调，不因阴影变得脏、糊或抢走脸部即可。
- **灰色、深色与彩色衣物**：用稳定的底色保留衣物本色，再根据叠层、内侧、材质和角色气质决定是否增加深浅块面、排线、图案或质感。简洁服装可以很干净，复杂或标志性服装也可保留较多细节；不以细节多少本身判定合格，只要层级清楚、主体不脏不糊即可。
- **阴影与质感边界**：不用固定的阴影数量、灰阶比例或表现技法绑死不同角色。平整块面、少量排线、较丰富灰度或较弱质感都可以按角色和感觉使用。验收看结果：结构要清楚，主体不脏不糊，脸部不得因写实光影出现模拟肤色，整体仍能读为干净的漫画或线稿插画。
- **构图与气质**：单张画面有明确主体和自然动作，表情克制、有生活感；留出大块安静的白色空间。场景道具只保留动作所需的部分，不自动加入标题、标签或装饰性信息图。
- **颜色**：黑白与灰阶是默认视觉基底，红黄蓝是优先考虑的风格点缀，但都不是强制配额或禁色表。服装、毛发、道具、机器人或非人角色的身体外壳，可按角色识别度和整体感觉选择纯黑白、灰阶、局部点色或较大面积的固有色。例如哆啦A梦的身体可以是全蓝，也可以转为全灰；服装鲜明的角色可保留固有色，也可提高灰度。颜色的多少不单独决定是否合格，只要身份清楚、画面协调、背景克制即可。这种弹性不得覆盖脸部肤色的硬标准：浅色肤色的脸仍然不铺模拟肤色。

## 真人照片转绘

把照片当作**身份与姿势参考**，再把它重画为漫画角色。先提取并保留：脸型大轮廓、眼距与眼形倾向、鼻嘴位置、发型大形、气质、服装轮廓、头饰或配件的辨识部位。随后主动删去照片里的皮肤明暗、真实毛发、相机光影和材质颗粒。

- **脸部优先漫画化**：眼睛以清晰上眼线、简洁瞳孔和少量眼睑线表达；鼻梁和鼻尖不做真实体积建模；嘴唇不画真实唇纹或体积。浅色肤色的脸颊、下巴和脖子以白色留白为硬标准，不铺肉色、粉色、米色或其他模拟肤色；黑色、深棕色或特殊肤色按角色设定保留干净底色。妆容、瞳色、伤疤、花钿和面部配饰等必要识别细节可点色，但不将它们扩展成脸部肤色。身份相似来自比例和特征组合，而非对照片每一处阴影的复刻。
- **头发与饰品**：头发先画发型轮廓、刘海和少量发束，黑发用整块黑色与少量高光留白，不逐根勾发丝。复杂头饰优先保留剪影、主花形和节奏感最强的几组垂饰；重复珠链、花纹和材质肌理可合并为简洁符号，不能用密集排线填满。
- **服装**：先根据照片判断衣物的固有深浅和身份作用。黑色或深灰衣物可保留干净的灰黑底色；白色或浅色衣物可保持大量留白，也可根据结构增加较丰富阴影。对身份识别有帮助时，可保留局部或较大面积的服装固有色，也可转成灰阶。不以颜色面积、阴影数量或单一纹理技法判定成败，以脸部肤色、身份、结构和整体协调为先。
- **失效判定**：若浅色肤色的脸部被铺成肉色、粉色、米色或照片式肤色，则不合格。若脸部保持干净留白，角色身份清楚，比例、手脚和动作可信，且整体协调，则可以在极简线稿、较丰富灰阶、时装插画感或保留部分固有色之间灵活变化。

## 生成流程

1. 明确当前图的主体身份、可识别特征、年龄与体型、动作、画幅、必要道具和服装固有深浅。先锁定脸部肤色规则，再按识别度和画面感觉决定服装、道具、非人身体的颜色与阴影。真人照片转绘时，先列出必须保留的 3–6 个身份锚点。若用户点名现有角色，保留其识别特征，再用本 Skill 重画比例和笔触；未点名则设计新主体。
2. 将约束写进同一条生图提示词：**主体与动作 → 身份锚点 → 年龄与自然结构 → 漫画化脸部 → 脸部肤色硬标准 → 黑白线稿基底 → 服装、固有色与阴影的弹性处理 → 反向约束**。不要只写“简笔画”，那会丢失本风格的细节与比例。
3. 用户要求出图时，使用可用的图像生成工具，默认内置 `image_gen`；用户要求修改现有图时按编辑任务处理。按用户指定位置保存；否则项目任务保存到当前工作目录，采用不覆盖原件的 `_CO` 文件名。
4. 查看成图，按以下优先级验收：**脸部肤色正确 → 角色身份清楚 → 年龄、比例、手脚和动作可信 → 整体画面协调 → 服装颜色与阴影是否服务于角色**。浅色肤色的脸部被铺成肉色、粉色、米色或照片式肤色是硬失败；黑色、深棕色或特殊肤色则核对是否保留角色设定。服装、道具、非人身体的颜色面积和阴影不作统一硬限，不因全蓝、全灰、保留固有色或较丰富灰阶而单独判定失败。只针对影响上述优先顺序的偏差迭代并复查。交付时给出图片路径和实际验证结果。

## 提示词骨架

> 画一张【画幅】的【主体】插画，正在【动作】，保留【3–6 个身份识别点】。人物保持与角色年龄、体型相符的自然比例；若基于照片，保留脸型、五官位置、发型与辨识配件，但先转成简洁的日式漫画角色脸。浅色肤色的脸部不得填肉色、粉色、米色或其他模拟肤色，必须以白色留白为主，可根据画面感觉保留少量灰色阴影；若角色设定为黑色、深棕色或特殊肤色，则保留干净、稳定的角色底色。纯白无纹理背景，以清楚黑色手绘线和黑白灰关系为视觉基底。服装保留【服装与道具】，颜色、灰度、阴影数量和质感按角色识别度、服装结构与整体感觉决定：可以纯黑白、全灰、局部点色，也可以保留较大面积的角色固有色；红黄蓝优先但不强制，非人角色的身体外壳也可全色或全灰。验收以脸部肤色正确、身份清楚、比例与手脚可信、整体协调为先；不要无意义的 Q 版、浅色脸部铺肤色、真实皮肤纹理、杂乱背景、文字或水印。
