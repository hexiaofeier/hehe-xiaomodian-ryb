# 盒盒小墨点 Skill

`hehe-xiaomodian-ryb` 用于生成或改绘自然比例的黑白漫画线稿人物、宠物和动物头兽人，以少量红、黄、蓝作为识别点色。

它适合：

- 将照片转为保留身份锚点的日式黑白漫画角色。
- 绘制人物、宠物、动物头兽人或角色立绘。
- 制作白底、细线、少量浅灰阴影的生活感插画。

它不适合替代写实肖像、全彩厚涂、Q 版角色或复杂信息图。

## 安装

克隆仓库后，将 `skills/hehe-xiaomodian-ryb/` 复制到客户端的 Skill 目录：

```text
Codex:  ~/.codex/skills/hehe-xiaomodian-ryb/
Claude: ~/.claude/skills/hehe-xiaomodian-ryb/
```

新开会话后可显式调用：

```text
使用 $hehe-xiaomodian-ryb 把这张照片改成黑白简笔画。
```

## 画面原则

- 自然人体和动物骨架，拒绝大头小身与萌系夸张比例。
- 纯白无纹理背景；外轮廓略重，内部使用清楚纤细的黑线。
- 浅色皮肤以白色留白，不填肉色；黑色或棕色皮肤按角色设定保留干净底色。
- 浅色衣物只用少量平整浅灰块交代遮挡；深色衣物使用稳定的灰黑色块。
- 红、黄、蓝只用于 1–3 处必要识别细节，可用于妆容、瞳色、伤疤、花钿、配饰或道具。

## 公开版边界

本仓库不包含用户照片、角色截图、第三方角色素材或生成示例图。使用者应提供自己有权使用的参考图，并在生成时说明角色、动作、衣物固有深浅、必要道具和点色位置。
